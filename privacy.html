Privacy Policy

Ask Here for ChatGPT · Last updated: November 9, 2026 · Contact: mehdigho1994@gmail.com

Short version: This extension does not collect, sell, or upload your data to the developer. Selected text is only used to ask a question inside your own ChatGPT session.

1. Who we are

Ask Here for ChatGPT (“the Extension”) is an unofficial browser extension that helps you select text on chatgpt.com and view a reply in a sticky note on the same page. It is not affiliated with, endorsed by, or sponsored by OpenAI.

2. Data we do not collect

The Extension does not:

  • Send your prompts, selected text, or ChatGPT answers to the developer’s servers
  • Run analytics, ads, or tracking pixels
  • Sell or share user data with third parties
  • Require you to create an account with the developer

3. Data processed on your device

To provide the feature, the Extension may temporarily process on your device:

  • Text you select and any optional question you type
  • Reply content returned inside your ChatGPT tab, shown in the sticky note
  • Short-lived technical state (queue / request ids) stored with chrome.storage.session so the feature can continue if Chrome restarts the extension worker

Selected text is submitted only to ChatGPT in a temporary helper tab on chatgpt.com / chat.openai.com, using your existing ChatGPT login and OpenAI’s own services. That helper tab is closed when the reply is delivered.

4. Permissions

  • storage — save temporary in-progress request state in the browser session only
  • Host access to chatgpt.com and chat.openai.com — show the Ask here UI and run the helper ask on ChatGPT pages

5. Third-party services

ChatGPT / OpenAI process the question and answer under their own terms and privacy policy. Review OpenAI’s policies at openai.com/policies.

6. Children’s privacy

The Extension is not directed at children under 13 and does not knowingly collect children’s data.

7. Changes

If this policy changes, the “Last updated” date above will be revised. Continued use after changes means you accept the updated policy.
